# Café-central-app

## DESCRIPCIÓN
En este proyecto se desarrollará una aplicación para una cafetería,
que permita a los clientes realizar compras desde cualquier dispositivo móvil.

## PROBLEMA QUE RESUELVE
Ayudará a los clientes a realizar pedidos con mayor practicidad,
sencillez y rapidez.

## FUNCIONALIDADES PRINCIPALES
- La aplicación contará con un formulario de registro, el cual permitirá a los
 clientes realizar su registro para acceder a ella
- Menú para consultar los productos que se venderán
- Consultar precios
- Y la sección para realizar pedidos
